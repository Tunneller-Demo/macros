# Prototipo desechable: dirección visual

Código de usar y tirar para elegir el aspecto de la app. No es la app ni debe copiarse tal cual en ella.

```sh
npm --prefix prototype/direccion-visual install
npm --prefix prototype/direccion-visual run dev
```

Abre http://localhost:5173/macros/?variant=A o `?variant=B`. La barra negra de abajo cambia de variante y rellena o vacía el formulario. Las flechas del teclado también cambian de variante.
